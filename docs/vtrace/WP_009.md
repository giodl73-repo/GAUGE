# WP-009 — Frequency source custody and interpretation correction

Status: accepted for implementation, 2026-10-26.
Parents: WP-007/008, REQ-003 sources, REQ-010 promotion boundary; DIM-07.

## Reader contract

Keep the working Rust/WASM frequency portfolio explorer and its numeric results.
Audit all twelve retained round-trips/day quantities. Their one broad source
registry entry supplies neither original timetable bytes nor route/date/segment/
operating-day record locators. Relabel all twelve source-needed; retain values,
IDs, historical source ID, scores, tiers, URL inputs, thresholds and scenarios.
Missing custody does not establish that a value is wrong. No primary quantity
is verified by this package. Preserve the original finding as its exact Git blob
before withdrawing its national-network and intervention-target conclusions.

Frequency averages do not measure service span, actual departure spacing or
operating days. The Sunset Limited 0.4/day is a rounded historical model claim,
not the exact fraction 3/7 and not proof of daily service. Counts for named brands
and endpoint labels do not establish all-segment/all-day coverage. Seven-point
adequacy is a provisional model choice; do not present it as a sourced standard.
A twelve-entry model distribution cannot establish national representativeness.

Expose exact derivative corpus/finding/registry custody plus a generated audit
JSON/table without WASM. Add native Rust export metadata: each original quantity's
actual evidence label, false primary-source verification, and a versioned evidence
boundary with explicit unobserved span/spacing/days, representativeness, operational
capacity/reliability, demand/access/cost/modal-shift/savings and false authorities.
Retain existing gauge-frequency-v2 fields and share inputs; additions are evidence
metadata only. Reuse the same Rust evaluator in a small native JSON replay binary
and WASM; no scoring/gap algorithm is copied to JS. Add native/WASM byte parity
coverage for baseline, one edit, portfolio edits and exact-bar boundary.

TAXLANE updates only its GAUGE transportation description/caveat and assertions;
no accounting, ledger, rates, candidate or fiscal-admission change. TRACKER owns
coordination and the final snapshot. Other satellites, ICELINES and BISECT no-op.
